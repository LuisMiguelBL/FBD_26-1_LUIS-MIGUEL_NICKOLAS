# Universitary Database Project

This repository was created for the course **Fundamentals of Databases** at the Universidade Federal Rural de Pernambuco - Unidade Acadêmica de Serra Talhada (UFRPE - UAST).

The purpose is to design and implement a relational database for a fictitious medical clinic system, applying best practices in database implementation.

## Tools Used

- **SGBD:** PostgreSQL with pgAdmin
- **Modeling Tool:** brModelo v3.32
